# Multimodal AI-Generated Content Detection

This project develops a multimodal system for detecting AI-generated content.

The system analyzes:

- Text
- Images
- Multiple images
- Metadata
- Multimodal combinations

## Main Models

- RoBERTa for text
- Vision Transformer (ViT) for images
- Neural network for metadata
- Multimodal fusion model

## Main Features

- AI-generated probability for text
- AI-generated probability for each image
- Multiple-image analysis
- Multimodal AI-generated probability
- Support for human and AI-generated content combinations

## Project Structure

- `app/` - Application
- `data/` - Datasets
- `models/` - Trained models
- `src/` - Python source code
- `notebooks/` - Experiments
- `tests/` - Testing
